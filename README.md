# 🎲 The Dicee Game

A simple two-player dice game built using HTML, CSS, and JavaScript. Refresh the page to roll the dice and see who wins!

## 🌐 Live Demo

[Play The Dicee Game](https://jumaila-junaid.github.io/The-Dicee-Game/)

## 📌 About the Project

The Dicee Game is a beginner-friendly web development project created to practise JavaScript, DOM manipulation, and working with images.

Built as part of The App Brewery web development course.

The game rolls two dice and displays the winner based on the numbers generated. If both dice show the same number, the result is a draw.

## ✨ Features

- 🎲 Two-player dice game
- 🔢 Random dice number generation
- 🏆 Automatic winner or draw result
- 🔄 Refresh the page to play again
- 🎨 Simple interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/jumaila-junaid/The-Dicee-Game.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use Live Server.
4. Refresh the page to play again.
